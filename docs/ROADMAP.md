# 路线图

> 当前版本：`0.0.2`，本文保留历史规划，运行时行为以源码和插件 README 为准。

## 已完成

- 标准仓库结构、测试基座、打包脚本和敏感文件排除规则。
- 官方 App 正文源：Android 设备画像、设备注册、registerkey、批量正文解密和 gzip 处理。
- 番茄 API 备用正文源：官方 App 请求失败时自动接管正文。
- 多源 fallback：两个源默认启用，按 `order` 顺序尝试，不再限制只能使用单个源。
- 段评索引与评论 ID 缓存修复。
- `3`、`5`、`10` 章预下载设置按用户选择生效。
- 网页正文源移除：实测只能返回截断或转义片段，无法作为稳定正文源。

## 后续维护建议

1. 番茄移动端接口变化时，先在 `docs/API.md` 记录新的请求路径、参数和响应样本，再修改解析代码。
2. 任何设备身份、Cookie、Token 和日志都只保留在本机运行时目录，不提交到仓库。
3. 发布前运行 `python3 scripts/package.py`，并在 Kindle 或 Android KOReader 上做一次真实取文验证。
4. 如果官方 App 源临时失效，优先检查备用源响应和 fallback 日志，不要把 Kindle 硬件信息当作 Android 设备身份。

## 不在当前版本中的方案

- 网页正文源已移除，不再作为运行时 fallback。
- 整书 EPUB 方案没有接入当前逐章 HTML 阅读流程，不作为本次发布功能描述。
- 本项目不引入额外后端；番茄 API 备用源是插件直接访问的外部接口。
